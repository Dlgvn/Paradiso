## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, icon-only sidebar icon internal padding |
| sm | 8px | Compact element spacing, status tab padding, pill gaps |
| md | 16px | Default element spacing, card inner padding, nav item spacing |
| lg | 24px | Section padding, grid column gap, card outer margin |
| xl | 32px | Layout gaps, section headers margin |
| 2xl | 48px | Major section breaks, page top padding |
| 3xl | 64px | Page-level spacing, backdrop gradient bottom fade height |

Exceptions:
- Touch targets on mobile bottom nav: minimum 44px height (accessibility)
- Sidebar width (desktop): 64px fixed (w-16 Tailwind)
- Bottom nav height (mobile): 64px fixed

Source: RESEARCH.md Pattern 6 (AppShell), standard 8-point scale

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Card metadata, status labels, tooltip text |
| Label | 16px | 400 (regular) | 1.5 | Tab labels, nav tooltips, button text |
| Heading | 20px | 600 (semibold) | 1.2 | Page section headings, card hover title |
| Display | 28px | 600 (semibold) | 1.1 | Empty state tagline, primary page title |

Font stack: `font-sans` via `next/font/google` (Inter) — `font-family: 'Inter', ui-sans-serif, system-ui, sans-serif`

No serif fonts. Weight contrast (400 vs 600) creates all hierarchy — no italic styles. Display size (28px) provides sufficient visual dominance through scale alone.

Source: CONTEXT.md decisions ("All sans-serif, varied weights (Inter or Geist). No serif. Weight contrast creates hierarchy.")

## Interaction Contracts

### Backdrop Layer

- Poster image fills `fixed inset-0 -z-10` layer via `next/image fill + object-cover`
- Gradient scrim sits above poster: `bg-gradient-to-b from-transparent via-[rgba(10,10,15,0.6)] to-[#0a0a0f]`
- Crossfade on section change: framer-motion `AnimatePresence` + `motion.div`, `opacity` 0→1, duration 0.6s, ease `easeInOut`
- Fallback when no poster: render only the gradient scrim (no image layer). Background remains `#0a0a0f`.
- `src` prop is `string | null` — null triggers fallback automatically

### Sidebar (desktop, md+)

- Width: 64px fixed (`w-16`), full viewport height (`h-screen`)
- Background: `bg-base-surface/80 backdrop-blur-sm` (subtle glass)
- Nav items: icon-only, 48px × 48px touch target, centered icon (24px)
- Active state: background pill `bg-accent-DEFAULT/20 rounded-xl` behind icon
- Icon color at rest: `text-accent-silver` (`#a8b4cc`); active: `text-accent-DEFAULT` (`#4f7cff`)
- Tooltip: shadcn Tooltip, side="right", delay 200ms, shows nav item label
- Hidden below `md:` breakpoint

### Bottom Nav (mobile, below md)

- Height: 64px fixed, bottom-0, full width
- Background: `bg-base-surface/90 backdrop-blur-md border-t border-accent-silver/10`
- 5 items: Movies | Books | Series | Search | Profile — equal width flex
- Active state: icon tints to accent (`text-accent-DEFAULT`); no label text shown
- Touch target: full column height (64px)

### Frosted Glass Card

- Border radius: `rounded-2xl` (16px)
- Background: `bg-white/5 backdrop-blur-md`
- Border: `border border-white/10`
- Shadow: `shadow-[0_8px_32px_rgba(0,0,0,0.4)]`
- Blur intensity: `backdrop-blur-md` (8px) — not xl, to avoid GPU jank on mobile

### Status Tabs

- shadcn Tabs component: Watchlist | Watching | Completed | Dropped
- Default: Watchlist selected on load
- Tabs switch the full grid — no page navigation, client-side state only
- Tab style: underline variant (no filled background); active tab underline in `accent.DEFAULT`

### Empty State (Movies/Books/Series when library is empty)

- Full-screen cinematic: backdrop renders with dark gradient (no poster)
- Centered content: display-size tagline + body copy + primary CTA button
- No ghost/skeleton cards
