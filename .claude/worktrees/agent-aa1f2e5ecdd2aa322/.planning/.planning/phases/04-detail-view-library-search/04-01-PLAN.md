**2. GenrePills.tsx** — no `'use client'` needed (pure render)
- Props: `{ genre: string | null }`
- If `genre` is null or empty after trim, return null.
- Split on comma, trim each, filter empty strings.
- Render `<div className="flex flex-wrap gap-2">` containing `<span>` per tag with `className="px-3 py-1 rounded-full text-xs font-medium bg-white/10 backdrop-blur-sm border border-white/20 text-white/80"`.
- Export named `GenrePills`.

**3. RatingEditor.tsx** — `'use client'`
- Props: `{ itemId: string; currentRating: number | null; mediaType: MediaType }`
- Import `Star` from `lucide-react`, `useOptimistic`, `useTransition` from `react`, `toast` from `sonner`, `updateItemRating` from `@/app/actions/library`.
- State: `optimisticRating` via `useOptimistic(currentRating)`. Local `hoverIndex` state (number | null) for desktop hover preview.
- Render label "Your Rating" in `text-xs uppercase tracking-widest text-[#94a3b8] mb-2`.
- Render a row of 10 star buttons. Each star is wrapped in a `<button>` with `className="flex items-center justify-center w-11 h-11 cursor-pointer"` (44px touch target). The Star icon is `size={24}`.
- Filled logic: star index (1-based) <= `hoverIndex ?? optimisticRating ?? 0` gets `className="text-[#eab308] fill-[#eab308]"`. If hovering, use lighter `text-[#eab308]/60 fill-[#eab308]/60`. Empty stars get `text-[#94a3b8]`.
- `onMouseEnter` on each star button sets `hoverIndex` to that star's 1-based index. `onMouseLeave` on the row div sets `hoverIndex` to null.
- `onClick` on star N: if `optimisticRating === N`, call `handleRate(null)` (clear). Otherwise call `handleRate(N)`.
- `handleRate(rating)`: inside `startTransition`, set optimistic rating, call `updateItemRating(itemId, rating)`. If result has error, toast `"Couldn't save rating. Try again."` with `duration: 4000`.
- If `optimisticRating` is null and `hoverIndex` is null, show `<span className="text-xs text-[#94a3b8]">Tap to rate</span>` below the star row.
- Export named `RatingEditor`.

**4. DeleteConfirmRow.tsx** — `'use client'`
- Props: `{ itemId: string; mediaType: MediaType; onDeleted: () => void }`
- Import `deleteMediaItem` from `@/app/actions/library`, `toast` from `sonner`, `useState`, `useTransition` from `react`.
- State: `confirming` boolean (default false), `isPending` from useTransition.
- At rest (`confirming === false`): render a single button "Remove from library" with `className="text-[14px] font-[400] text-[#ef4444] border border-[#ef4444]/40 rounded-lg px-4 py-2 cursor-pointer hover:bg-[#ef4444]/10 transition-colors"`. onClick sets `confirming = true`.
- When `confirming === true`: render a row with:
  - Label: `"Remove from library?"` in `text-[14px] text-[#f1f5f9]`
  - Cancel button: `text-[14px] text-[#94a3b8] cursor-pointer` — onClick sets `confirming = false`
  - Remove button: `bg-[#ef4444] text-white text-[14px] font-[400] rounded-lg px-4 py-2 cursor-pointer disabled:opacity-50` — disabled when isPending
  - On Remove click: `startTransition(async () => { onDeleted(); const result = await deleteMediaItem(itemId); if (result?.error) toast("Couldn't remove item. It may still be in your library.", { duration: 4000 }) })`. Call `onDeleted()` first (optimistic — closes sheet immediately).
- Row gap: `gap-3`, items-center, flex.
- Export named `DeleteConfirmRow`.
