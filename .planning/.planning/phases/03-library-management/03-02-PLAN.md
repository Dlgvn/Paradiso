**File 1: `src/lib/api/omdb.ts`**

This is NOT a 'use server' file — it's a plain module imported only by Server Actions. Create with these exact exports:

```typescript
// Types
export interface OmdbSearchResult {
  imdbID: string
  Title: string
  Year: string
  Type: 'movie' | 'series'
  Poster: string  // URL or "N/A"
}

export interface OmdbDetailResult {
  imdbId: string
  title: string
  year: string | null
  genre: string | null
  director: string | null
  plot: string | null
  posterUrl: string | null
  imdbRating: string | null
  type: 'movie' | 'series'
}
```

**`searchOmdb(title: string, type: 'movie' | 'series')`:**
- Read `process.env.OMDB_API_KEY` — throw Error('OMDB_API_KEY not configured') if missing
- Build URL: `https://www.omdbapi.com/?apikey=${apiKey}&s=${title}&type=${type}`
- Fetch with `{ next: { revalidate: 300 } }` (5-minute cache)
- Parse JSON response
- If `data.Response === 'False'`: return `{ results: [], error: data.Error === 'Movie not found!' || data.Error === 'Series not found!' ? undefined : data.Error }`
- Map results: return `{ results: data.Search ?? [] }`
- Return type: `Promise<{ results: OmdbSearchResult[]; error?: string }>`

**`getOmdbDetails(imdbId: string)`:**
- Build URL: `https://www.omdbapi.com/?apikey=${apiKey}&i=${imdbId}&plot=short`
- Fetch with `{ next: { revalidate: 3600 } }` (1-hour cache)
- Map ALL fields through N/A filter: `value !== 'N/A' ? value : null`
- Fields to map: Title, Year, Genre, Director, Plot, Poster, imdbRating, Type
- Return mapped OmdbDetailResult object
- CRITICAL: Poster must be mapped as `data.Poster !== 'N/A' ? data.Poster : null` — passing "N/A" string to Next.js Image causes errors (Pitfall 4)

**File 1: `src/lib/api/open-library.ts`**

Create with these exact exports:

```typescript
export interface OlSearchResult {
  key: string           // "/works/OL...W"
  title: string
  author_name?: string[]
  first_publish_year?: number
  cover_i?: number      // internal cover ID
}
```

**`searchOpenLibrary(query: string)`:**
- Build URL params: `q=${query}`, `limit=20`, `fields=key,title,author_name,first_publish_year,cover_i`
- CRITICAL: The `fields=` parameter is MANDATORY since January 2025 — omitting it loses cover_i and author_name (Pitfall 1 in RESEARCH.md)
- Fetch `https://openlibrary.org/search.json?${params}` with `{ next: { revalidate: 300 } }`
- If !res.ok, return `{ results: [], error: 'Open Library unavailable' }`
- Return `{ results: data.docs ?? [] }`
- Return type: `Promise<{ results: OlSearchResult[]; error?: string }>`

**`getOlCoverUrl(coverId: number, size: 'S' | 'M' | 'L' = 'M')`:**
- Return `https://covers.openlibrary.org/b/id/${coverId}-${size}.jpg`
- This is a pure function, not async

**`getOlWorkId(key: string)`:**
- Extract work ID from key: `key.replace('/works/', '')`
- Example: `/works/OL45883W` -> `OL45883W`
- This is used as the external_id for books in media_items
