**Update `src/components/library/MediaCard.tsx`:**

Ensure these specific behaviors are implemented (some may already exist from Plan 03-03, but verify and polish):

1. **Optimistic status update with rollback:**
   - Use `useOptimistic` for status display
   - On status selection from dropdown: immediately show new status (optimistic)
   - Call `updateItemStatus(id, newStatus)` via `useTransition`
   - If result contains error: revert optimistic state back to original status
   - Show toast: "Couldn't save change. Try again." — duration 4000ms, position bottom-center
   - Install/use sonner toast library (or shadcn toast if available from Phase 1): `import { toast } from 'sonner'` — add `<Toaster />` to the app layout if not already present

2. **Optimistic favorite toggle with rollback:**
   - Same pattern as status: `useOptimistic` for is_favorite
   - On heart tap: immediately toggle (optimistic)
   - Call `toggleFavorite(id, !currentFavorite)` via `useTransition`
   - On error: revert, show same toast message

3. **Hover overlay debounce (desktop):**
   - Add 80ms delay on `mouseleave` before hiding the overlay
   - Use `setTimeout` + `useRef` for the timer
   - Cancel the timer on `mouseenter` (prevents flicker when moving cursor within the card/dropdown area)
   - This specifically prevents the Radix DropdownMenu dismiss issue (RESEARCH.md Pitfall 6)

4. **Date completed auto-set:**
   - When status changes TO 'completed': the Server Action already handles date_completed
   - No additional client-side logic needed, but verify the optimistic update doesn't need to track this

**Update `src/components/library/MediaListItem.tsx`:**

Apply the same optimistic update + toast error pattern to the list view controls. The list item's status badge and favorite heart should behave identically to the grid card.

**Toast setup (if not already present):**
If sonner is not installed, run `npm install sonner`. Add `<Toaster position="bottom-center" />` to `src/app/(app)/layout.tsx` (or the root layout). The Toaster component is a single global instance.
