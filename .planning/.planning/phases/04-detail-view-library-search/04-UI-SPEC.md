# Phase 4 — UI Design Contract

> Visual and interaction contract for Phase 4: Detail View + Library Search. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This contract extends the cinematic design language established in Phases 1–3. All tokens, card patterns, overlay patterns, and layout shell carry forward unchanged. Phase 4 introduces the cinematic bottom-sheet detail view (with backdrop blur scoped to the sheet), a 10-star rating editor, an inline delete confirmation, and a functional My Library search tab replacing the Phase 3 placeholder.

## Interaction Contracts

### Detail Sheet Open / Close

- **Trigger open (desktop + mobile):** Click/tap anywhere on a `MediaCard` or `MediaListItem` that does NOT land on the status dropdown trigger or favorite heart button. Those buttons use `e.stopPropagation()` to prevent sheet opening.
- **Open animation:** Sheet slides up from screen bottom. Duration: 300ms ease-out. Starting transform: `translateY(100%)`. Ending transform: `translateY(0)`.
- **Height:** Sheet occupies 85–90% of viewport height. Remaining 10–15% at top shows the blurred library behind — visually confirms navigation context.
- **Backdrop scrim:** Semi-transparent `bg-black/50` covers the visible library strip behind the sheet. Tap on the scrim closes the sheet.
- **Dismiss (tap):** Tap the scrim above the sheet. Triggers close animation.
- **Dismiss (drag):** Drag down on the sheet's drag handle or body. When drag distance exceeds 80px, sheet snaps closed. Duration: 200ms ease-in. Implementation: shadcn `Sheet` component from `@/components/ui/sheet.tsx` with `side="bottom"`.
- **Close animation:** Sheet slides down: `translateY(100%)` over 250ms ease-in.
- **Sheet content:** Rendered inside the sheet while it is open. Unmounted after close animation completes.

### Rating Editor Interaction

- 10 star icons in a row. Each star: 24px icon, padded to 44px touch target (`w-11 h-11` containing div).
- State: `currentRating` (0–10, 0 = no rating).
- Hover preview (desktop): Hovering over a star fills all stars up to that index in a lighter gold (`#eab308/60`). Cursor moves away: reverts to `currentRating` display.
- Tap to set: Tap star at index N → sets rating to N. Optimistic: fills stars 1 through N with `#eab308`. Fires `updateRating(item.id, N)` Server Action.
- Tap to clear: Tap the star at the current rating value → sets rating to null. Optimistic: clears all stars. Fires `updateRating(item.id, null)`.
- Error: Server Action returns error → toast "Couldn't save rating. Try again." Duration: 4000ms. Optimistic state rolls back.

### Delete Inline Confirmation

- **At rest:** A single button labeled "Remove from library" with destructive text color (`#ef4444`), no fill, thin `#ef4444/40` border, `text-[14px] font-[400]`.
- **Tap "Remove from library":** Button row expands inline (no modal, no navigation) to reveal: label "Remove from library?" + `[Cancel]` button (secondary style, `#94a3b8` text) + `[Remove]` button (destructive fill, `#ef4444` background, white text). Expand animation: height 0 → auto over 150ms ease-out.
- **Tap Cancel:** Confirmation row collapses back to single button. 150ms ease-in.
- **Tap Remove (confirmed):** Fires `deleteItem(item.id, item.media_type)` Server Action. Sheet closes immediately (optimistic — don't wait for server). Library page revalidates via `revalidatePath`. If Server Action returns error: sheet stays closed, toast "Couldn't remove item. Try again."

### Library Search (My Library Tab)

- **Tab activation:** User selects "My Library" tab on `/search`. `LibrarySearchTab` renders. Server Component pre-loads full library for default type (Movies) into `LibrarySearchTab` props.
- **Type switch:** MediaTypeSelector shows Movies / Books / Series. Switching type: fetches items for that type (Server Action or route param), resets `?q=` param, clears search input.
- **Search input:** `LibrarySearchInput` with `defaultValue={searchParams.get('q') ?? ''}`. On change: `useDebouncedCallback(300ms)` → `router.replace` with updated `?q=` param.
- **Filter:** `filterLibrary(items, query)` function in `lib/search/filter.ts`. Case-insensitive substring match on `title`, `genre`, `director` (movies/series), `author` (books). Filter applied on every render when `q` param is present.
- **Initial load with `?q=`:** Server Component reads `searchParams.q` and passes as `initialQuery` to `LibrarySearchTab` — filter applied on first render, no flash of unfiltered results.
- **Results display:** `LibraryGrid` with `MediaCard` components. Same grid breakpoints as library pages. Clicking a card in search results opens `ItemDetailSheet`.

### Sheet Backdrop (Cinematic)

- **Scope:** Scoped within the sheet only — does NOT affect the global `BackdropContext` or `BackdropLayer`.
- **Layer stack within sheet (bottom to top):**
  1. `next/image fill object-cover` — poster image fills the entire sheet area
  2. `backdrop-blur-xl bg-black/60` div — blurs the poster and darkens
  3. `bg-gradient-to-t from-black via-black/80 to-transparent h-2/3` div — bottom-anchored gradient pull-to-dark
  4. Sheet content (poster thumbnail, title, metadata, synopsis) — floated on top, `relative z-10`
- **Fallback (no poster_url):** Replace image with `bg-gradient-to-b from-[#16162a] via-[#0a0a0f] to-black`. No broken image state.

## Loading and Error States

### Detail Sheet Loading

- State: Sheet opens before all item data is confirmed (future-proofing for async detail fetch).
- UI: Poster area shows a `bg-[#12121a]` placeholder with a subtle pulse animation (same `animate-pulse` class). Title area shows two skeleton bars (80% width, then 40% width). Genre pills show 2–3 skeleton pill shapes.
- Duration: skeleton visible until data resolves. On success: skeleton fades out (opacity 0 over 120ms), real content fades in.
- For Phase 4 where item data is passed via state (not fetched async), skeleton is only shown if the `poster_url` image is still loading.

### Library Search — Empty Results

- State: Query is non-empty, `filterLibrary()` returns 0 results.
- UI: Centered block below the search input.
  - Heading: "No results for '[query]'" (20px/600/`#f1f5f9`)
  - Body: "Try a different title, director, author, or genre." (14px/400/`#94a3b8`)
  - No CTA button.

### Library Search — Empty Library (No Items for Type)

- State: User switches to a type that has 0 items in their library (e.g. no books added yet), query is empty.
- UI: Same `EmptyState` component pattern from Phase 3.
  - Heading: "No [Movies / Books / Series] yet" (20px/600/`#f1f5f9`)
  - Body: "Add some from the search tab to get started." (14px/400/`#94a3b8`)
  - CTA: "Search Now" (accent button) → navigates to Add New tab.

### Rating Save Error

- State: `updateRating` Server Action returns error.
- UI: Toast notification (bottom-center, sonner): "Couldn't save rating. Try again." Duration: 4000ms. Optimistic rating state rolls back.

### Delete Error

- State: `deleteItem` Server Action returns error after sheet closes optimistically.
- UI: Toast: "Couldn't remove item. It may still be in your library." Duration: 4000ms. User must refresh to confirm state.
