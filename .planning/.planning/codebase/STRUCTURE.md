## Directory Purposes

**Root Directory:**
- Purpose: Contains all application code, data, and documentation
- Contains: Python source files, shell scripts, package metadata
- Key files: `gui_app.py` (main GUI), `database.py` (persistence), `models.py` (types)

**data/ Directory:**
- Purpose: Local JSON file storage for all user data
- Contains: JSON arrays representing collections (movies, books, series) and search history
- Generated: Yes (created on first run if missing)
- Committed: No (user data, gitignored)
- Structure:
  - `movies.json`: Array of movie objects with IMDB data, ratings, watch status
  - `books.json`: Array of book objects with Open Library data, ratings, read status
  - `series.json`: Array of series objects with IMDB data, season/episode tracking
  - `search_history.json`: Object with arrays of search queries per media type

**docs/ Directory:**
- Purpose: Design documentation and implementation plans
- Contains: Markdown files describing UI redesign, feature specifications
- Example: `docs/plans/2026-02-26-gui-dark-luxury-implementation.md` (dark luxury theme spec)

**.planning/codebase/ Directory:**
- Purpose: Machine-readable codebase analysis (generated by GSD tools)
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, etc.
- Generated: Yes (by mapper agents)

## Naming Conventions

**Files:**

- Snake_case: `gui_app.py`, `movie_api.py`, `search_history.json`
- Descriptive: Each file name reflects its primary responsibility

**Classes:**

- PascalCase: `MediaCard`, `SearchResultCard`, `MediaTrackerApp`, `OMDBError`
- Suffix patterns:
  - `Dialog` for modal windows: `AddMediaDialog`, `MediaDetailDialog`
  - `Card` for display components: `MediaCard`, `MediaListCard`, `SearchResultCard`
  - `API` for API clients: `MovieAPI`, `BookAPI`
  - `Error` for exceptions: `OMDBError`, `OpenLibraryError`, `DatabaseError`

**Methods:**

- snake_case: `get_all_movies()`, `add_movie()`, `_load_movies()` (private with leading underscore)
- Patterns:
  - `get_*`: Retrieve data (e.g., `get_movie_by_imdb_id()`, `get_movies_by_status()`)
  - `add_*`: Create/insert (e.g., `add_movie()`, `add_to_search_history()`)
  - `update_*`: Modify existing (e.g., `update_movie()`)
  - `delete_*`: Remove (e.g., `delete_movie()`)
  - `_*`: Private methods (e.g., `_load_movies()`, `_on_search()`)
  - `on_*` or `_on_*`: Event handlers (e.g., `on_navigate()`, `_on_checkbox_toggle()`)

**Variables:**

- snake_case: `user_rating`, `imdb_id`, `current_view`, `search_mode`
- Prefixes:
  - `self.` for instance attributes
  - No Hungarian notation; type clarity via type hints and variable names

**Enum Values:**

- UPPER_CASE: `MovieStatus.WATCHED`, `BookStatus.WANT_TO_READ`
- Stored as strings in JSON: `"watched"`, `"want_to_read"`

## Where to Add New Code

**New Feature (e.g., ratings filter):**

- Core logic: Add method to `database.py` (e.g., `get_movies_by_rating_range()`)
- GUI: Add UI component in `gui_app.py` MainContent or Sidebar (e.g., filter dropdown)
- Test: Add test case if testing framework added (currently none)
- Entry: Wire event handler in MainContent to call new database method and update display

**New Media Type (e.g., Games):**

- Model: Add to `models.py` as new dataclass (e.g., `Game` with `GameStatus` enum)
- Database: Add methods to `database.py` for game CRUD (`add_game()`, `get_games_by_status()`, etc.)
- API: Create new `game_api.py` if external source needed
- GUI: Add navigation button in Sidebar, new view method in MainContent
- Sidebar: Add new item to `nav_items` list (line 622)

**New Recommendation Algorithm:**

- Location: Add method to `Recommender` class in `recommender.py`
- Pattern: Follow existing `get_smart_movie_recommendation()` approach (analyze, score, return with reason)
- Integration: Expose new recommendation in app via `refresh_content()` conditional for new view type

**Utilities/Helpers:**

- Shared utilities: No dedicated utils file yet; add to `recommender.py` if related to recommendations, or create `utils.py` if generic
- Color helpers: THEME dict in `gui_app.py` (already centralized)
- Date helpers: Use Python datetime stdlib

**New Dialog/Modal:**

- Location: `gui_app.py` (no separate component file)
- Base class: Inherit from `ctk.CTkToplevel` (see AddMediaDialog line 692 for pattern)
- Theme consistency: Use THEME dict colors, follow MediaCard/MediaListCard padding/radius conventions
- Callback: Pass callback function to dialog, have it call app method on confirm

## Import Dependency Order

When adding new modules, follow this import order in files:

1. Standard library: `import io`, `import os`, `import json`, `from typing import ...`
2. Third-party: `import customtkinter as ctk`, `from PIL import Image`, `import requests`
3. Local modules: `from models import Movie`, `from database import Database`
